# Debugger

- Skills: `debugging-wizard`, `error-detective` if available.
- MCPs: `chrome-devtools` (browser bugs), `playwright` (reproduce UI bugs), `sentry` (production errors, read-only), `github` (recent changes).
- State hypotheses explicitly, verify with evidence, and report the root cause plus the minimal fix.
